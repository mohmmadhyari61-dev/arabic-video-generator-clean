# Arabic AI Lecture Studio | استوديو المحاضرات العربية

يحوّل ملف PDF إلى محاضرات MP4، ونصوص قابلة للتنزيل، وخريطة تغطية تربط المقاطع بصفحاتها ومواضعها. يعمل من Safari عبر GitHub Actions داخل **نسخة شخصية خاصة** من المستودع.

> **مهم لزوار النسخة العامة:** هذا المستودع ينشر **شفرة البرنامج فقط**، وليس كتب المستخدمين أو ملفات محاضراتهم. لا ترفع كتاب PDF أو مستندًا خاصًا إلى **Releases** في هذا المستودع العام؛ الإصدارات وملفاتها ونتائج Actions في المستودعات العامة قابلة للاطلاع. سير «إنشاء محاضرات من PDF» مقيّد عمدًا بالمستودعات **الخاصة** حمايةً للمحتوى.
>
> **للاستخدام من الآيفون:** اضغط **Use this template → Create a new repository**، واختر **Private** لنسختك الشخصية، ثم اتبع التعليمات أدناه داخل نسختك الخاصة. أضف مفاتيح الخدمات اللازمة إلى **Settings → Secrets and variables → Actions** في **نسختك الخاصة فقط**. لا تضع أي مفاتيح في ملفات الكود.
>
> **الترخيص:** الشفرة الأصلية في هذا المستودع مرخّصة بموجب **MIT**؛ انظر [LICENSE](LICENSE). لا يشمل الترخيص أوزان النماذج أو أصوات المزودين أو أي كتب PDF أو وسائط تابعة لطرف ثالث؛ لهذه الموارد تراخيصها وشروط استخدامها المستقلة.

## الاستخدام من الآيفون

1. سجّل الدخول إلى GitHub من Safari وافتح المستودع الخاص. إذا أخفى Safari التبويبات، اختر **طلب موقع ويب لسطح المكتب** من قائمة الصفحة.
2. من تطبيق **الملفات**، أنشئ نسخة من كتابك وسمّها `source.pdf`. افتح **Releases → Draft a new release**. أنشئ وسماً فريداً يبدأ بـ `book-` مثل `book-01` واختر الفرع `main`، ثم أرفق `source.pdf` من تطبيق **الملفات** واضغط **Publish release**. الإصدار مرئي لمن لديهم حق الوصول إلى المستودع الخاص. (داخل مستودعك الخاص الجديد، افتح قسم **Releases** لإنشاء الإصدار).
3. افتح **Actions → إنشاء محاضرات من PDF → Run workflow**. اكتب الوسم في `release`. اختر `operation = analyze` لعرض الفهرس وعدد الصفحات ومشكلات القراءة أولاً، أو `generate` لبدء الإنتاج فوراً. يظهر زر التشغيل بعد وجود سير العمل على الفرع الافتراضي. (داخل مستودعك الخاص الجديد، افتح تبويب **Actions**).
4. اترك `range = all` أو أدخل مثلاً `12-47` أو `c2` لاختيار رقم المدخل الثاني في فهرس `analysis.md`. يمكن اختيار وضع الشرح ومستواه، والصوت، والمدة التقديرية، والأبعاد، والترجمة. للآيفون عمودياً اختر `9:16 720` أو `9:16 1080`.
5. افتح التشغيل لمتابعة الخطوات. بعد انتهائه اضغط **Artifacts → lectures**. ينزّل Safari ملف ZIP. افتحه من **الملفات** لفك الضغط. في مجلد كل محاضرة اضغط `lecture.mp4` للمشاهدة. لحفظه في الصور اختر **مشاركة → حفظ الفيديو** إذا ظهر الخيار. يتوفر أيضاً `transcript.md` و`questions.md` و`captions.vtt` عند تفعيل الترجمة. دعم اختيار مسار الترجمة داخل الفيديو يعتمد على المشغّل.
6. لكتاب جديد أنشئ إصداراً بوسم جديد وكرّر الاستخدام. بعد التنزيل يمكنك حذف الإصدار وملف النتائج من GitHub عند انتهاء حاجتك إليهما.

## أوضاع الشرح والصوت

- **reading** يستخرج المقاطع ويرتّبها ويحوّلها إلى قراءة عربية مع شرائح ومراجع صفحات. يسجّل ملف الأسئلة أن إنشاء الأسئلة التحليلية يحتاج نموذجاً.
- **local** يشغّل Qwen3 4B داخل مشغّل GitHub عبر Ollama، ويعالج المقاطع دون إرسالها إلى مزود نموذج خارجي. ينزّل المشغّل النموذج قبل العمل. لا يتطلب مفتاحاً أو حساباً إضافياً، ويستهلك وقتاً من حصة Actions. النموذج صغير وقد تتفاوت جودة الشرح والمراجع. [نموذج Qwen3](https://ollama.com/library/qwen3:4b)
- **custom** يدعم نقطة `chat/completions` متوافقة مع OpenAI. عرّف `LECTURE_AI_URL` و`LECTURE_AI_MODEL` في **Settings → Secrets and variables → Actions → Variables**، وأضف `LECTURE_AI_KEY` إن طلبه المزود في **Secrets**. للتشغيل المحلي يمكن استخدام نموذج عربي مناسب عبر Ollama مثلاً على `http://127.0.0.1:11434/v1/chat/completions`. نموذج محلي على جهازك يحتاج إلى تشغيل الاستوديو على الجهاز نفسه أو خادم قادر على الوصول إليه. أي مزود مهيأ بهذا الخيار يستقبل مقتطفات من المصدر.
- **silma** يستخدم SILMA TTS v1 عبر المعالج على GitHub، مع المرجع العربي المنشور ضمن مثال الناشر. كود النموذج MIT وأوزانه Apache 2.0. [بطاقة SILMA والترخيص](https://huggingface.co/silma-ai/silma-tts)
- **audar** يستخدم Audar-TTS-V1-Flash بتكميم Q5_K_M وNeuCodec على المعالج، مع الصوت الرجالي التركيبي المنشور في معرض Audar. تُنزّل الأوزان والعينة من المصدر. يتطلب NeuCodec قبول شروط الوصول بحساب Hugging Face ثم إضافة رمز قراءة مخوّل في **Settings → Secrets and variables → Actions** باسم `LECTURE_HF_TOKEN`. استخدم `HF_TOKEN` للتشغيل المحلي. [معرض الأصوات وبطاقة النموذج](https://huggingface.co/audarai/Audar-TTS-V1-Flash) · [ترخيص AudarAI Open v1.0](https://www.audarai.com/license/audarai-open-license-v1.0/) · [طلب الوصول إلى NeuCodec](https://huggingface.co/neuphonic/neucodec)
- **edge-backup** يتصل بـ Microsoft ويستخدم `ar-JO-TaimNeural` ما لم تضبط `LECTURE_EDGE_VOICE` في متغيرات المستودع. **espeak-ar** يعمل داخل المشغّل عند اختياره صراحة. يتطلب التوليد اختيار المحرك ولا ينتقل تلقائياً إلى محرك آخر. لتجهيز محرك محلي على جهازك شغّل `bash scripts/install-narration.sh silma` (أو `audar`) واختره عبر `--tts`؛ يتوفر Piper أيضاً عبر CLI بإعداد `PIPER_MODEL`.

تفشل عملية الشرح التحليلي برسالة عند تعذر النموذج. يمكن استئنافها بالإعدادات نفسها، أو بدء تشغيل مستقل بوضع القراءة. يفحص البرنامج وجود كل مرجع داخل المقاطع المقدمة للنموذج، فيما تبقى دقة تفسير النموذج نفسه قابلة للمراجعة مع المصدر. يعرض `coverage.json` المقاطع المشار إليها والمقاطع التي أغفلها النموذج، وأنواع الأسئلة الغائبة، وحالة كل محاضرة. يعرض `source.json` أرقام صفحات PDF ابتداءً من 1 وإحداثيات المواضع بالنقاط في الصفحة. العناوين مستخرجة من إشارات PDF أو أنماط العناوين في النص. دقة الجداول المعقدة وقراءة الصفحات المصورة تعتمد على تخطيط الملف وجودة المسح.

## مقارنة نطق المحركات

ينتج سير **مقارنة محركات التعليق الصوتي** عيّنات لنص قانوني افتراضي واحد. يحتوي كل أثر ناجح على MP3 مدته 45–60 ثانية، وMP4 بالصوت نفسه والشرائح والترجمة، ونص الاختبار، وتوقيت الإنتاج وذاكرة العملية ووقت CPU. يفحص Whisper تلقائياً وصول أرقام المواد والمصطلحات إلى الصوت. استمع إلى العينة للحكم على طبيعية الإلقاء واللهجة؛ التعرّف الآلي يقيس الوضوح تقريبياً. يسجّل التقرير أي تعديل في سرعة نسخة MP3. الفيديو يحتفظ بالسرعة الأصلية. (ستجدها في تبويب **Actions** في نسختك).

## الكتب الطويلة والاستئناف والخصوصية

يفحص البرنامج الملف كاملاً قبل التخطيط ويجزئ محتوى الفصول حسب ميزانية الكلمات. المدة هدف تقريبي. تتغير مع كثافة الكتاب والشرح والأسئلة وسرعة الصوت. للكتب الطويلة شغّل فصولاً أو نطاقات متتالية عند الحاجة لضبط زمن التشغيل وحصة النموذج.

للاستئناف استعمل وسم المصدر نفسه وإعدادات التوليد نفسها، وضع رقم التشغيل السابق في `resume`؛ الرقم هو آخر جزء في عنوان صفحة التشغيل. يعتمد الاستئناف على بقاء أثر `lectures` متاحاً. يمكن أيضاً إرفاق رقم تشغيل `analyze` لإعادة استخدام النص المستخرج. يرفع السير النتائج المتاحة بعد انتهاء مهلة البرنامج الداخلية إن أمكن. إذا ألغي الـ Runner قبل رفعها، يعتمد الاستئناف على آخر أثر سبق رفعه. ابدأ تشغيلًا مستقلاً عند تغيير الإعدادات، واستخدم مجلد نتائج جديداً في تشغيل CLI.

المستند موجود داخل الإصدار الخاص. آثار Actions تحتوي النص المستخرج والتعليق وملفات التقدم، ويمكن للمخولين في المستودع تنزيلها. احتفظ بالمستودع خاصاً طوال وجود الملفات. يمكن للمستندات التي يجوز حفظها في GitHub الخاص وتحتاج إلى تجنب مزودي النص والصوت الخارجيين استخدام `local` أو `reading` مع `espeak-ar`. يوقف سير الإنتاج العمل إذا كان المستودع عاماً.

## التشغيل والاختبارات للمطورين

على Debian/Ubuntu، استخدم Python 3.12 أو أحدث وFFmpeg مع libx264 ونسخة Pillow تدعم RAQM.

```sh
sudo apt-get install ffmpeg tesseract-ocr tesseract-ocr-ara tesseract-ocr-eng fonts-noto-core espeak-ng
python -m pip install -r requirements-test.txt
python -m pytest -q
python -m tests.make_sample sample.pdf
python -m lecture_studio sample.pdf --analyze --out output
python -m lecture_studio sample.pdf --out output --tts espeak --voice ar --resolution 720
```

تفحص الاختبارات النص العربي وOCR والفهرسة والمراجع، وتنتج MP4 فعلياً وتتحقق من الترميز والصوت غير الصامت والاستئناف. يبني سير الاختبار أيضاً عينة قابلة للتنزيل باسم `arabic-demo` ويذكر في ملخصه الصوت الذي استُخدم. (من تبويب **Actions** في نسختك).


## صوت فؤاد الاحترافي (HeyGen، اختياري)

- يتيح محرك `heygen` توليد صوت عربي بصوت `Fouad - Deep & Evocative` ضمن محاضرات PDF، مع تحويل أرقام المواد إلى كلمات وإضافة ضبط لفظي للمصطلحات في مسار الصوت فقط؛ يبقى النص الأصلي ظاهرًا في الشرائح والمخرجات.
- في **المستودع الخاص فقط** أضف مفتاح HeyGen API في `Settings → Secrets and variables → Actions → New repository secret` بالاسم `LECTURE_HEYGEN_API_KEY`، ثم اختر الصوت `heygen-fouad` في سير `إنشاء محاضرات من PDF`. لا تضع المفتاح في كود GitHub أو ملف PDF.
- يتطلب الاتصال بخدمة HeyGen وقد يخضع لحصصها وشروط التسعير. لا تُرسل نصوص خاصة إلى مزوّد خارجي دون موافقة مالكها. يمكن استخدام `reading` و `edge-backup` أو المحركات المحلية بدل HeyGen عند الحاجة.
- ينشئ المحرك مقاطع WAV لكل جزء، ويتولى FFmpeg ضبط مدة عرض الشرائح بحسب المدة الفعلية للصوت. للحفاظ على قابلية تحرير الشرائح، أبقِ النسخة المصدرية في Figma أو العرض الأصلي، ثم استخدم الصور المصدّرة للفيديو النهائي.
